# Operación Mercadona: Chancleto — proyecto Android v0.2

Este ZIP contiene el proyecto fuente Android con el juego integrado. **No es todavía un APK compilado**: el entorno actual no tiene Android SDK ni Gradle instalados para generar y verificar el binario aquí.

## Compilar el APK
1. Sube el contenido de esta carpeta a un repositorio GitHub.
2. Abre **Actions** y ejecuta **Build Chancleto APK** (Run workflow).
3. Descarga el artefacto **Chancleto-APK** al finalizar.
4. Dentro encontrarás `app-debug.apk`, instalable para pruebas en Android.

También puedes abrir el proyecto en Android Studio y compilar con `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
